# VPS deployment surface

## Source inputs

The paths in `vps-source-paths.txt` are the tracked inputs used to build and operate the web application on the VPS.

## Not part of the VPS web deployment

- `src-tauri/` — desktop application wrapper
- `src-tauri/target/` — generated Rust build output
- `docs/research/` — reverse-engineering notes and evidence
- `tools/` — local extraction and investigation utilities
- `recovered-swfs/` — local recovered/decompiled Flash files
- `.renderer-backups/` — temporary local safety copies

## Generated release

`build/` is generated by `npm run build` and intentionally excluded from Git.

The final runtime release manifest will be generated after the SvelteKit prerender configuration is fixed and a full production build succeeds.
